# 电影《牛来》角色 3D 模型来源与机器人外壳采用方案

更新时间：2026-09-02

## 目标更正

本项目需要的不是现实牛、奶牛或通用卡通牛，而是电影《牛来》中出现的黄色拟人角色：短角、半眯眼、紫色宽嘴、黄色毛绒躯干和人形四肢。网络模型必须先满足这一形象，再讨论能否改造成机器人外壳。

## 结论

已经找到精确对应电影角色的 3D 打印模型，但暂未找到官方电影制作方公开的源模型，也没有找到采用 OSI 开源许可或 CC0/CC BY 等开放许可的精确角色模型。

最省工的私用原型路线是下载 Nexprint 的拆件版 3MF，在本地用于形体和分件参考；若要把改造后的外壳随比赛项目公开、上传仓库、上传 IMA 或商业化，必须先取得模型作者及角色权利方的明确许可。第三方 3MF/STL 文件本身不得放入本项目仓库或 IMA。

## 推荐的偷懒路线

### 路线 1：48 小时比赛私用原型

1. 用户自行登录 Nexprint，下载 `牛来拆件newnx.3mf`；不绕过登录或平台限制。
2. 在 Bambu Studio 中先查看各拆件、包围盒和薄壁，不直接整只打印。
3. 用 Blender 或 FreeCAD 只复制外观比例，选取头、躯干两个外观件做本地适配。
4. 保留项目现有参数化机械骨架：两只 TT 电机、轮子、电池、ESP32-S3、PAN/TILT/MOUTH 三舵机的位置由 FreeCAD 决定，不由角色网格决定。
5. 先打牛角、嘴壳、头部接口环三个小样，确认外观与舵机运动不干涉后再打整壳。

这条路线最快，但仅限团队内部原型。比赛提交、作品展示、奖项或赞助是否构成许可中的非个人/商业用途存在不确定性，最好先向作者取得书面同意。

### 路线 2：可公开、可持续开发版本

1. 把精确模型只当视觉参考，不导入或复制其网格到最终 CAD。
2. 根据电影公开画面制作自己的正、侧、背三视图，再用 Tripo/混元 3D 生成外观草模。
3. 在 Blender 中重新拓扑、空心、分件；在 FreeCAD 中重建全部接口、螺丝柱、公差和舵机支架。
4. 保存生成服务条款、输入参考来源和人工重建过程；比赛前再核对角色 IP 使用规则。

这条路线不能自动消除电影角色本身的知识产权风险，但能避免把第三方作者的数字模型当作自己的开源资产再分发。

## 机械改造边界

- 电影角色网格只负责皮肤，不负责承力。
- 承力件继续使用 FreeCAD 参数化结构：底盘、TT 电机仓、电池托盘、舵机支架、80 × 50 mm 头部接口和防倾结构。
- 外壳目标不是统一缩放整个手办，而是按结构包络重新切割：头壳、上躯干、背盖、嘴壳至少四件。
- 头壳底部增加项目自有接口，嘴部围绕定位舵机轴单独分件；不要打印死在身体上。
- 先做低质量 0.28 mm 层高试壳，验证干涉和重心，再用 0.16–0.20 mm 打最终外壳。
