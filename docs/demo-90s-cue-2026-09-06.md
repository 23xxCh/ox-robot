# 牛来 · 90 秒路演词（Checkpoint 2 / 交卷）

计时按秒。超时就停，不要补聊天或跑步。

| 秒 | 你做什么 | 你说什么 |
|---|---|---|
| 0–10 | 指黄牛脸 | 「这是牛来。靠近时它先停着，等人喊它。」 |
| 10–25 | 喊「牛来」或按 KY-004 | 「人在旁边喊它，才用礼貌人格听、想、说。走私有大脑，不经过小智云。」 |
| 25–40 | 手伸到超声前（约 30 cm），先别喊 | 「靠近，腿马上冻，吐槽立刻停。冻结在板端 C 里。」 |
| 40–55 | 腿应已停 | 「靠近不等于开始聊天。超时也不等于确认没人。」 |
| 55–80 | 手拿开，等约 8 秒 | 「人离开几秒，它才自己晃、自己吐槽。那是笔记本私有大脑，不是小智云。」腿随机小晃；大约十一秒一句。 |
| 80–90 | 再把手伸回去 | 「再靠近，吐槽立刻停，等人喊它。仓库 ox-robot。不演跑步，不打开小智官网。」 |

## 失败预案

| 现象 | 当场怎么说 | 立刻做什么 |
|---|---|---|
| 喊了不说话 | 「键在 GPIO 18，唤醒词是单次『牛来』。BOOT 也可以。」 | 按 KY-004，不要打开官网 |
| 一直转 | 「左后应在 GPIO 9，不要接 12（充电指示）。360° 没吃到中位也会转。SECRET 只晃约 800 ms 就会停。」 | 确认黄线 10/11/9/13；不行就拔那只黄线 |
| 不冻不晃 | 「超声 TRIG 8 ECHO 17。没有近距时要等 8 秒才晃。」 | 手再近一点；或等 8 秒 |
| 花屏 | 「21/47 是屏 SPI，灯和键不能占。」 | 不演示灯，只演示脸和说话 |
| 有人问聊天 | 「靠近先冻着等。喊『牛来』才礼貌聊。人走了才吐槽。/life 只改人设，不驱动腿。」 | 不要打开 xiaozhi.me；笔记本必须开着 brain :8000 |

## 不要说的话

- 「它现在只会说妈妈。」（夜里已改成礼貌听、想、说）
- 「它会自己走路/跑步。」（没人时只是短促乱晃）
- 「我们用了小智官方云。」
