# 牛来 · 90 秒路演词（Checkpoint 2 / 交卷）

计时按秒。超时就停，不要补聊天或跑步。

| 秒 | 你做什么 | 你说什么 |
|---|---|---|
| 0–10 | 指黄牛脸 | 「这是牛来。有人时它是玩具，不是聊天机器人。」 |
| 10–25 | 喊「牛来牛来」或按 KY-004 | 「它只会说妈妈。这是板上的录音，不经过小智云。」 |
| 25–40 | 手伸到超声前（约 30 cm） | 「靠近，它马上停，只会说妈妈。冻结在板端 C 里，不经小智云。」 |
| 40–55 | 腿应已停 | 「超时不等于确认没人。所以它不会因为测距失败就自己玩。」 |
| 55–80 | 手拿开，等约 8 秒 | 「人离开几秒，它才敢自己晃一下，并说一句本地吐槽。」随机小晃约 800 ms 然后停。不要等连续走路。 |
| 80–90 | 再把手伸回去 | 「再靠近，腿和吐槽都会立刻停。仓库 ox-robot。我们不演云端闲聊，不演跑步。」 |

## 失败预案

| 现象 | 当场怎么说 | 立刻做什么 |
|---|---|---|
| 不说妈妈 | 「键在 GPIO 18，唤醒词是牛来牛来。BOOT 也可以。」 | 按 KY-004，不要打开官网 |
| 一直转 | 「左后应在 GPIO 9，不要接 12（充电指示）。360° 没吃到中位也会转。SECRET 只晃约 800 ms 就会停。」 | 确认黄线 10/11/9/13；不行就拔那只黄线 |
| 不冻不晃 | 「超声 TRIG 8 ECHO 17。没有近距时要等 8 秒才晃。」 | 手再近一点；或等 8 秒 |
| 花屏 | 「21/47 是屏 SPI，灯和键不能占。」 | 不演示灯，只演示脸和妈妈 |
| 有人问聊天 | 「人前不聊天是产品。笔记本 /life 是人设页，不是小智云，也不驱动腿。」 | 不要打开 xiaozhi.me，不要切到 /life 假装真机在聊 |

## 不要说的话

- 「它现在能跟你闲聊。」
- 「它会自己走路/跑步。」
- 「它能跟你闲聊。」（吐槽是板上三句录音，不是大模型）
- 「我们用了小智官方云。」
